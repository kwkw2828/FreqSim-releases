# FreqSim

AC解析専用の回路シミュレータ FreqSim の配布用リポジトリです。ソースコードは置いていません。

紹介・使い方・使用許諾の要点は、配布ページを見てください。
<https://kwkw2828.github.io/software/freqsim/>

## ダウンロード

[最新のリリース](https://github.com/kwkw2828/FreqSim-releases/releases/latest)の「Assets」から、どちらかの zip を入手してください。

- 名前が `_with-runtime.zip` で終わるもの: .NET ランタイム同梱版。迷ったらこちら
- それ以外: .NET 10 デスクトップランタイム（x64）を別に入れて使う版
